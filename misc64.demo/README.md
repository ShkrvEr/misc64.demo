# Структура VmProject

Это каркас проекта из спецификации. Сейчас он только запускается; виртуальные инструкции пока не реализованы.

Из папки проекта:

```powershell
dotnet run
```

Собрать без запуска:

```powershell
dotnet build
```

Открыть в Visual Studio можно файл `VmProject.csproj` или папку `C:\Desktop\riscv64.demo`.
